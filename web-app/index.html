How It Works

In order to protect research ethics, intellectual property, and institutional confidentiality, this application operates on a Serverless Client-Only Architecture:

  • No database or servers are managed by us. The website acts only as a static package delivered to your browser.
  • The browser requires read/write access to a single Project Root Directory on your computer. All files (manuscripts, codebooks, logs, progress states) are read from and written to this local folder directly.
  • Direct HTTPS requests are sent from your browser to Google Gemini API endpoints using your personal key. No third party (including this website) has access to your credentials or data.

Ethical Guideline Notice

Depending on data confidentiality (e.g. unpublished manuscripts, proprietary datasets, or medical review metadata), it is highly recommended to configure Vertex AI API keys inside an enterprise Google Cloud project with disabled data logging to comply with IRB constraints.

Need help setting up Google AI Studio? View Guided Steps
  1. Sign in to the Google AI Studio Console with your Google Account.
  2. Click the Get API key button in the upper-left sidebar.
  3. Click Create API key.
  4. Choose either to link it to an existing Google Cloud project or automatically generate a new project.
  5. Copy the generated key (starts with AIzaSy) and paste it into the API Key field above.
Need help setting up Vertex AI? View Guided Steps
  1. Create or select a project in the Google Cloud Console.
  2. Enable the Vertex AI API for your project.
  3. Go to the Credentials Page, click + Create Credentials, and select API Key.
  4. For safety, click edit on the key, select Restrict Key under API Restrictions, and choose Vertex AI API. Save the key and paste it above along with your Project ID.
